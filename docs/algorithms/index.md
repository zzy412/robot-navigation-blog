# C++ 算法实现

本栏目主要记录我在机器人运动规划方向上的 C++ 算法实现与实验结果，重点围绕阿克曼转向无人车的路径规划与轨迹跟踪问题展开。

目前，我已经基于 **C++17 + CMake** 完成了以下内容的初步实现：

- 二维栅格地图建模
- A* 路径规划
- Hybrid A* 路径规划
- 阿克曼车辆运动学建模
- 碰撞检测
- 路径可视化与实验结果输出

与传统几何路径搜索相比，Hybrid A* 将车辆航向角和最小转弯半径等运动学约束纳入搜索过程，更适合阿克曼车辆的路径规划。
