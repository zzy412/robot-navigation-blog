# ROS 2 系统集成

本栏目主要记录我将运动规划与车辆仿真实验迁移到 **ROS 2 Jazzy** 平台上的过程。

在前期的独立 C++ 仿真基础上，我进一步在 Ubuntu / WSL2 环境下搭建了 ROS 2 工作空间，并实现了阿克曼无人车相关的基础节点。

目前已经完成的工作包括：

- ROS 2 Jazzy 环境配置
- `ackermann_navigation` 功能包创建
- Hybrid A* 路径规划节点
- 车辆运动学仿真节点
- 地图与路径发布
- RViz2 可视化显示

通过这一阶段，我将原本离线运行的算法实验逐步迁移到机器人软件系统环境中，为后续开展在线闭环控制打下基础。
