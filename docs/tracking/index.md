# 轨迹跟踪实验

本栏目主要记录我在车辆轨迹跟踪控制方向上的实验与分析，重点研究阿克曼无人车如何沿规划路径稳定运动。

在完成 A* 与 Hybrid A* 路径规划后，我进一步开展了基于 **Pure Pursuit** 的路径跟踪实验，用于分析车辆对参考路径的跟踪能力。

目前已经完成的实验包括：

- Pure Pursuit 基础跟踪实验
- 固定前瞻距离参数扫描
- 自适应前瞻距离对比
- 转向约束影响分析
- 速度规划实验
- 多场景跟踪性能评估

这些实验说明：**一条可规划的路径，并不一定能够被车辆高质量地跟踪**。因此，路径规划与轨迹跟踪需要结合起来分析。
