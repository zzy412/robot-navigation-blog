    移动机器人运动规划课程学习

    本栏目记录《Motion Planning for Mobile Robots》课程的学习内容。课程主要涉及机器人运动规划的基础理论、路径搜索算法、采样式规划方法和考虑运动约束的路径规划。

    Lecture 1：移动机器人运动规划概述

    主要学习机器人自主导航系统的基本架构，理解环境感知、定位、建图、路径规划与控制之间的联系。同时学习运动规划的前端路径搜索与后端轨迹优化，以及占据栅格、OctoMap、点云、TSDF 和 ESDF 等地图表示方法。

    Lecture 2：基于搜索的路径规划

    主要学习配置空间、图搜索基础，以及 BFS、DFS、Dijkstra、A、Weighted A 和 Jump Point Search（JPS）等算法。

    其中，A* 算法通过结合累计路径代价与启发式估计进行搜索：

    \[ f(n)=g(n)+h(n) \]

    这部分知识已经应用于当前 C++ 项目中的 A* 与 Hybrid A* 实现。

    Lecture 3：基于采样的路径规划

    主要学习概率路线图 PRM、快速扩展随机树 RRT、RRT-Connect、RRT* 和 Informed RRT* 等算法。

    重点理解随机采样、最近邻节点搜索、碰撞检测及搜索树优化等基本思想。

    这部分目前以理论学习为主，后续考虑使用 RRT* 作为路径规划对照算法。

    Lecture 4：考虑运动约束的路径规划

    主要学习 State Lattice、运动基元、边界值问题、Kinodynamic RRT* 和 Hybrid A*。

    对于采用阿克曼转向结构的车辆，路径规划不仅需要避开障碍物，还必须考虑车辆的非完整运动约束和最小转弯半径。

    本项目已将相关理论应用于 Hybrid A* 路径规划与车辆运动学仿真。

    课程学习总结

    通过前四讲的学习，逐步建立了从基础图搜索、随机采样规划到考虑车辆运动约束的路径规划知识体系。

    后续将继续结合 C++ 和 ROS 2 项目，通过代码实现、算法可视化和对比实验加深对相关方法的理解。
